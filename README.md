# WHYDESCR1M — сайт-визитка с курсами

Одностраничный сайт на чистом HTML, CSS и JS, без сборки и зависимостей.
Стиль: глассморфизм, приглушённый фиолетовый акцент, живой фон и интерактивные блоки.

## Структура

```
site/
├── index.html   # разметка, две вкладки: «Курсы» и «Портфолио»
├── style.css    # стили, цвета заданы переменными в :root 
├── script.js    # данные, вкладки, конструктор курсов, портфолио, анимации
└── README.md
```
